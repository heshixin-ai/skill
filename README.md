# Skills

这个仓库用于集中保存个人 Skills，每个 Skill 使用独立文件夹。

## 已收录

### analyze-product

基于截图、页面和操作记录拆解 AI 产品，输出可追溯的用户旅程、Agent 输入输出契约与现状 / 建议架构。

- [使用与安装说明](./analyze-product/README.md)
- [Skill 入口](./analyze-product/SKILL.md)
- [完整示例：输入证据 → 分析报告 → 架构图](./analyze-product/examples/storyboard-demo/README.md)

### human-writing

中文写作 Skill，支持选题孵化、资料研究、长文创作和修改。

- [查看 Skill 说明](./human-writing/SKILL.md)
- 当前版本：1.2.0

## 目录约定

每个 Skill 文件夹以 `SKILL.md` 作为入口，可按需包含 `agents/`、`assets/`、`references/`、`scripts/` 和 `dist/`。
