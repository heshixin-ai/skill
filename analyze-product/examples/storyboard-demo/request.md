# 示例请求

使用 `$analyze-product` 分析 `input/observations.md` 中的分镜工坊记录。

这是一组虚构教学输入。只读分析，不操作真实产品，不联网补充产品信息。按 E001–E010 顺序还原一次三镜头分镜任务，覆盖局部失败、重试和上游修改。

请交付：

- 一句话判断、证据范围和缺口；
- 证据台账及用户旅程表；
- 材料中实际出现的 Agent 清单、I/O 契约及功能工具；
- 聊天、任务、画布和资产之间的冲突记录；
- 能从记录支持的现状，明确标注的合理推断，以及独立的改进建议；
- 带证据编号和图例的产品架构图；
- 风险、验收条件和未知项。

将“已确认 / 页面事实”“合理推断”“建议设计”“未知 / 尚未确认”分开。不要把教学样例当作真实观察，不要猜测厂商技术栈。此次不推导 Agent 的功能等价提示词。
